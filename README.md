# rrt-matlab-study

本仓库按“尽快产出一篇能写、能跑、能答辩的机械臂轨迹规划论文”来组织。

## 建议论文题目
基于目标偏置与路径剪枝的六自由度机械臂时间最优轨迹规划

## 论文主线
- 研究对象：六自由度串联机械臂
- 场景：存在障碍物约束的点到点轨迹规划
- 基线算法：RRT
- 改进点：
  1. 自适应目标偏置采样
  2. 动态步长扩展
  3. 父节点重选与局部重连
  4. 路径剪枝平滑
  5. 速度/加速度约束下的时间参数化

## 代码结构
- `src/main_paper_demo.m`：单文件可运行演示脚本
- `docs/paper_outline.md`：论文写作骨架

## 你要做的事
1. 在 MATLAB 中运行 `src/main_paper_demo.m`
2. 记录路径长度、规划时间、节点数、总执行时间等指标
3. 再补充基线 RRT 对照实验
4. 把图和表塞回论文

先把“能运行、能出图、能解释”的最小闭环做出来，再慢慢补细节，不走大而全路线。
