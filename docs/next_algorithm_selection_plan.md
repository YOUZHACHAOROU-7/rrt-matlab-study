# 下一阶段算法筛选与论文结果增强方案

## 1. 当前判断

当前 IGWO 在 benchmark 综合排名第 1，但不是所有测试函数均排名第 1。该结果可以支撑“综合性能较优”，但不足以支撑“所有函数绝对优于其他算法”。

论文中不能强行写“所有测试函数均最优”，否则容易被审稿人从数据表中发现逻辑问题。

## 2. 不建议的做法

不建议为了让 IGWO 全部第一而反复只筛选对 IGWO 有利的函数，或者人为删除不利函数。这样会造成实验选择偏差，论文风险较高。

## 3. 推荐做法

采用“算法候选池筛选”方式：

1. 保留当前 IGWO 作为候选算法 A；
2. 新增强算法候选 B：HGWO 类算法，参考 Halton 初始化、维度学习、交叉搜索、Cauchy 变异等策略；
3. 新增强算法候选 C：TFHO/改进火鹰算法类，参考 Tent 初始化和 Levy-Gaussian-Cauchy 混合扰动；
4. 在同一套 12~15 个 benchmark 函数上统一比较；
5. 以平均排名、第一次数、前二次数、Best/Mean/Std 和收敛曲线表现共同决定最终论文主算法。

## 4. 最终论文主线选择规则

若 HGWO 或 TFHO 的 benchmark 综合表现显著优于当前 IGWO，则论文主算法改为：

- “基于多策略改进火鹰算法的 ER7-900 机械臂轨迹规划”；或
- “基于混合灰狼优化算法的 ER7-900 机械臂轨迹规划”。

若 IGWO 仍综合最优，则保留当前题目：

- “基于多策略改进灰狼算法的 ER7-900 机械臂多目标轨迹规划”。

## 5. 对论文最稳的表述

不追求“所有测试函数全部第一”，而追求：

- 综合平均排名第 1；
- 多数函数取得最优或前二；
- Wilcoxon/Friedman 统计检验显著；
- 工程轨迹规划实验中优于主流对比算法；
- 消融实验能证明每个改进策略有效。

这种写法比强行追求全部第一更稳，也更符合期刊审稿逻辑。

## 6. 下一步执行

下一步应优先建立“候选算法横向筛选脚本”，统一测试：

- 当前 IGWO；
- HGWO 候选版；
- TFHO 候选版；
- PSO、GWO、WOA、SSA、HHO、DE 等对照算法。

筛选完成后，再决定最终论文算法，而不是提前锁死 IGWO。
