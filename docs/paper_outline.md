# 论文写作骨架

## 暂定题目
基于目标偏置与路径剪枝的六自由度机械臂时间最优轨迹规划

## 摘要写法
先写研究背景：机械臂在搬运、分拣、装配中的轨迹规划需要同时兼顾避障性、平滑性与执行效率。
再写问题：传统 RRT 在机械臂高维关节空间中存在随机性强、路径冗余大、执行时间长的问题。
然后写方法：本文提出一种面向六自由度机械臂的改进 RRT 方法，通过自适应目标偏置、动态步长扩展、父节点重选与路径剪枝来提高搜索效率，并结合速度/加速度约束下的时间参数化实现时间最优轨迹生成。
最后写结果：仿真实验表明，所提方法在路径长度、规划耗时、节点数量和总执行时间方面优于基线 RRT，能够生成更短、更平滑且执行效率更高的机械臂轨迹。

## 可直接写进正文的创新点
1. 将目标偏置概率设计为随规划进度自适应变化，减少无效随机扩展。
2. 根据当前节点与目标距离动态调整扩展步长，兼顾全局搜索效率与局部避障精度。
3. 在新节点插入时加入父节点重选和局部重连，降低路径冗余。
4. 在获得可行路径后进行快捷剪枝和平滑处理，并在关节速度与加速度约束下进行时间参数化，从而实现更优执行时间。
