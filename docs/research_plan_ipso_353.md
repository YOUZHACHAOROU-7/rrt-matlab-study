# 研究计划：改进粒子群算法与 3-5-3 多项式机械臂轨迹优化

## 1. 推荐题目

基于 Tent-Levy 改进粒子群算法的六自由度机械臂时间最优轨迹规划

## 2. 技术路线

1. 建立六自由度机械臂 D-H 运动学模型；
2. 选取关节空间起点、两个中间路径点和终点；
3. 构建 3-5-3 分段多项式插值轨迹；
4. 将三段插值时间作为优化变量；
5. 以总运行时间最小为目标函数；
6. 加入关节角度、速度和加速度约束；
7. 使用标准 PSO 与 Tent-Levy 改进 PSO 进行对比；
8. 输出收敛曲线、位移曲线、速度曲线、加速度曲线和末端三维轨迹。

## 3. 方法设计

### 3.1 Tent 混沌初始化

利用 Tent 混沌映射初始化粒子位置，提高初始种群分布均匀性。

### 3.2 动态惯性权重与学习因子

采用余弦型惯性权重和动态学习因子，使算法前期增强全局搜索，后期增强局部寻优。

### 3.3 Levy 飞行扰动

在粒子更新过程中加入 Levy 飞行扰动，用于增强跳出局部最优的能力。

### 3.4 贪婪保优与停滞重启

采用贪婪策略保留较优个体；当最优值长时间不变化时，对部分较差粒子重新初始化。
